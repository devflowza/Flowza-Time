## How to Use These Files

### For Email/Sharing
1. Print the HTML file directly to PDF using your browser's print function
2. Or open `attendance-quotation-001.html` in any web browser
3. Save/export as PDF for email distribution

### For Integration
1. Use the JSON file (`attendance-quotation-001.json`) to programmatically generate quotations
2. Modify client details and line items as needed
3. Generate new quotations by copying the JSON structure

### Customization Guide
When creating new quotations:
1. Update `quotationId` with new ID (e.g., QT-2026-002)
2. Update `date` and `validUntil` fields
3. Modify `client` information with actual customer details
4. Adjust `lineItems` array with services needed
5. Recalculate `summary` totals
6. Update `paymentTerms` for customized payment schedules
